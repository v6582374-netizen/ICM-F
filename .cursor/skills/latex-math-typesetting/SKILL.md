# LaTeX Math Typesetting

## Quick Start

写公式时先选对环境（`equation/align/\[ \]`），再检查符号与标点。

## Instructions

- 无引用公式用 `\[...\]`，需引用才用 `equation`
- 推导使用 `align`，避免 `eqnarray`
- 变量与矩阵符号遵守斜体/粗体约定
- 运算符使用标准命令（如 `\log`）
- 公式作为句子的一部分，标点放入公式内
