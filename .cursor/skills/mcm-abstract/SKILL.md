# MCM Summary Sheet (Abstract)

## Quick Start

摘要必须自包含、含具体数值结果，并在一页内完成。

## Instructions

- 按“问题重述—方法—结果—敏感性”结构写作
- 明确使用的建模技术与定量结论
- 避免复杂数学符号
- 首句需有现实语境“钩子”
- 严格控制在一页内
