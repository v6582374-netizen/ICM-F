# Assumptions Section Guidelines

## Quick Start

每条假设必须包含名称与明确论证，使用 `itemize` 结构。

## Instructions

- 使用 `itemize`，每条遵循“Assumption + Justification”格式
- 论证基于物理常识、数据限制或先验知识
- 新引入常量需立即定义符号与数值
