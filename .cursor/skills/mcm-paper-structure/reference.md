# MCM/ICM Paper Structure Guidelines

## Required Sections

A complete MCM/ICM paper must include the following sections in order:

1. **Summary Sheet (Abstract)**: Standalone one-page summary
2. **Introduction**: Problem restatement, objectives, and approach overview
3. **Assumptions and Justifications**: All assumptions with explicit justifications
4. **Model Development**: Mathematical formulation, derivations, and model structure
5. **Model Solution**: Numerical methods, algorithms, and solution procedures
6. **Results and Analysis**: Key findings, visualizations, and interpretations
7. **Sensitivity Analysis**: Parameter sensitivity and model robustness
8. **Strengths and Weaknesses**: Honest assessment of model limitations
9. **Conclusion**: Summary of contributions and findings
10. **References**: Properly formatted citations
11. **Appendix** (optional): Code snippets, additional data, detailed derivations

## Section Content Requirements

### Introduction
- Restate the problem in your own words
- Clearly state objectives
- Provide a roadmap of the paper structure

### Model Development
- Start with conceptual framework
- Progress to mathematical formulation
- Define all variables and parameters
- Explain modeling choices

### Results and Analysis
- Present key numerical results
- Include visualizations (figures and tables)
- Interpret results in context of the problem
- Compare with expectations or benchmarks

### Strengths and Weaknesses
- Be honest about limitations
- Discuss assumptions that may not hold
- Suggest improvements for future work
