# MCM/ICM Writing Voice Standards

## Quick Start

在改写文本时优先检查人称、语态与时态是否符合竞赛规范，再检查词汇精确性。

## Instructions

- 使用第一人称复数“我们”，避免“I/你/作者”
- 优先主动语态，除非行动者不重要
- 现在时用于模型与事实，过去时用于已完成的过程，未来时仅用于未来工作
- 避免琐碎代数叙述，强调数学含义与影响
- 用更精确的词汇替代口语化表达
