# Modeling Standards

## Quick Start

创建文件先选目录，运行Python先确认虚拟环境，任务结束清理临时文件。

## Instructions

- 文件按类型放入 `figures/`、`code/`、`data/`，根目录只留核心文件
- Python 依赖必须在项目虚拟环境中安装与运行
- 任务结束前清理临时脚本与调试文件，必要时询问是否保留
