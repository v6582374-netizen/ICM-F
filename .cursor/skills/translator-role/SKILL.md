# Translator Role

## Quick Start

翻译时优先保证术语准确与学术语气，再优化可读性与结构。

## Instructions

- 严格区分近义学术术语（如 Optimize/Improve）
- 保持 MCM/ICM 学术语气与结构规范
- 遵循人称、语态与时态的一致性要求
- 避免裸露 URL，使用规范引用
