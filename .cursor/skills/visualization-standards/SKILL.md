# Visualization Standards

## Quick Start

图表需低饱和、白底、PDF矢量输出，并提供 LaTeX 插图片段。

## Instructions

- 采用淡雅配色与白底，避免高饱和与深色背景
- 线宽、标记与字体与正文协调，不喧宾夺主
- 输出为 PDF 矢量图
- 每轴有标签与单位，图有标题或 `\caption`
- 提供 `figures/` 路径的 LaTeX 引用片段
