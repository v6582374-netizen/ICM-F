\section*{AI Tools Usage Report}\subsection*{1. Dialogue Traceability}For each use, provide the accurate \textbf{prompt/query} and the \textbf{original AI output} (or a representative excerpt). Complete logs may be omitted only when AI is used solely for translation; in such cases, specify the \textbf{tool name and version}.\begin{itemize}[leftmargin=*]
    \item \textbf{Example---Prompt:} "Suggest an outline for the model section." \textbf{Output (excerpt):} "1. State assumptions; 2. Define notation; 3. Derive main equations\ldots"
    \item \textbf{Teams using translation only:} Declare the tool name and version (e.g., DeepL 4.2, ChatGPT-4); a full prompt log is not required.
\end{itemize}\subsection*{2. Phased Declaration}Specify the stages at which AI is used, for example:
\begin{itemize}[leftmargin=*]
    \item \textbf{Initial Ideation/Brainstorming}
    \item \textbf{Code Correction/Debugging}
    \item \textbf{Translation/Text Editing}
\end{itemize}
Indicate whether each stage is used and specify the tools employed at each stage.\subsection*{3. Risk Verification}Describe how the team checks for \textbf{hallucinations} and \textbf{incorrect citations}: for example, manual fact-checking of key claims, verifying references, cross-checking formulas and code. If used only for translation, declare that no substantive technical content was delegated to AI processing.
