\section*{Report on Use of AI}
\label{sec:ai_report}

\textbf{OpenAI ChatGPT (Feb 2026, GPT-5.2 Thinking).}
We used AI as a \emph{research assistant and technical editor} to accelerate model design, verify internal logical consistency, and polish exposition. All modeling choices, assumptions, and final claims were determined and validated by the team.

\begin{enumerate}
   

    \item \textbf{Decision-rule simplification under data availability constraints}\\
    \textbf{Query:} Our initial curriculum model is too complex and requires unavailable fields (e.g., credits). Can we redesign it to depend only on course title/description while remaining defensible?\\
    \textbf{Output:} AI recommended (i) removing course-to-course redundancy to avoid unnecessary data requirements, (ii) using only text-derived course representations, and (iii) defining thresholds endogenously via within-program empirical quantiles (credit-weighted if available, uniform otherwise). This kept the rule set simple, portable, and reproducible while preserving interpretability.

    \item \textbf{Data source identification and cross-validation}\\
    \textbf{Query:} Where can we find reliable and authoritative public data sources relevant to this study, and how should we cross-validate them?\\
    \textbf{Output:} AI recommended authoritative sources including O*NET OnLine for occupational task structures, Bureau of Labor Statistics (BLS) for employment projections, and peer-reviewed literature for GenAI capability assessments. For cross-validation, AI suggested triangulating task importance scores across multiple O*NET releases and comparing employment trends with independent forecasts.

    \item \textbf{Robustness design and interpretation (occupation-set $O$ perturbations)}\\
    \textbf{Query:} The prompt asks whether our framework generalizes across institutions/programs. What is the single most critical sensitivity analysis, and how should we report it?\\
    \textbf{Output:} AI identified the target occupation set $O$ as the dominant external input and designed a narrow/medium/wide $O$ perturbation test. AI also prescribed stability metrics (label stability, TRANSFORM-set Jaccard, employability-rank stability) and helped interpret results conservatively: policy labels remained stable under reasonable $O$ perturbations, while fine-grained employability ranking can vary---therefore the model is transferable, but $O$ must be re-specified when extrapolating to new contexts.

\end{enumerate}

\textbf{Human verification.} We verified all intermediate outputs (course labels, threshold values, and robustness summaries) for logical consistency with the final decision rules, and revised any inconsistent intermediate drafts before inclusion in the paper.
