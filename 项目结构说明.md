# Repository guide

This repository is the reproducible research companion to *Reshaping Occupational DNA: Evolution Strategies in the Generative AI Era*. It contains the manuscript, source data, analytical code, derived artifacts, and figures needed to inspect the study from source records to reported findings.

## Structure

```text
main.tex                 manuscript entry point
sections/                manuscript sections
references.bib           bibliographic sources
occupational_dna/                    analytical pipelines and tests
data/raw/                source datasets and curriculum records
data/processed/          derived task, scenario, and robustness artifacts
figures/                 manuscript figures
assets/                  README research figure
build/main.pdf           compiled manuscript
```

## Analytical flow

The analysis begins by selecting heterogeneous representative occupations from O*NET descriptors. It then derives a weighted Task DNA for each occupation, maps tasks to a nine-dimension Gen-AI capability scale, and simulates task-share shifts under adoption scenarios. The final stage evaluates course portfolios on employability contribution, humanistic value, and AI overlap, followed by sensitivity analysis over the target occupation set.

Use the root [README](README.md) for the research summary and the shortest reproduction path. [`data/README.md`](data/README.md) records data provenance and refresh instructions.
